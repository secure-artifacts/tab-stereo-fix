浏览器立体声修复（软件）

下载 TabStereoFix-v版本号.zip，解压后打开 TabStereoFix 文件夹，双击 TabStereoFix.exe。
也可以双击「打开立体声修复.bat」。不需要安装 Python。
已经打开时再双击，只会把窗口提到前面，不会关掉。

本程序用官方 Python 运行，TabStereoFix.exe 带 Python Software Foundation 的数字签名。
请下载 v1.6.0 及更新版本。旧版 PyInstaller 压缩包容易被杀毒软件误报。

不要下载名叫 default.exe 的文件。那是旧版中文文件名上传失败后的名字。

使用说明

必须从本软件点「打开」来启动浏览器。
关掉后再从任务栏、开始菜单或桌面图标打开，声音进不了 VoiceMeeter / VoiceMeeter AUX / CABLE / Line 1。

1. 选一个用户
2. 点「打开（关掉 Wide AEC）」
3. 只用软件拉起来的这套浏览器
4. 这套浏览器关掉后，再打开本软件，选同一用户，再点「打开」

不要从任务栏、开始菜单、桌面图标自己开。

点「开机启动」可让软件开机后自己出现。只打开本软件，不会自动打开浏览器，开机后仍要点「打开」。

要恢复：选同一套，点「关闭（恢复）」
只动你选的这一套。其它浏览器不关。不改 VoiceMeeter / AUX / CABLE / Line 1。
